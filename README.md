# szcore_garage

SzCore v1.4.0-rc1 garage/impound module.

Supports public, job/gang and shared garages, multiple access points, state/type filtering, runtime garage registration, impound fees/reasons, occupied spawn checks and persistent vehicle integration.

Dependencies: `oxmysql`, `szcore`, `szcore_vehicles`, `szcore_vehiclekeys`, `szcore_ui`.
